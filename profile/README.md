# RISA-3D

> RISA-3D keeps member forces, load cases, and design checks in one frame view so the spreadsheet reads the same model.

## Four Beats

1. **Name the frame.** Give the RISA-3D session a short title before you edit members or loads.
2. **Pin the live members.** Keep current beams, columns, and cases on the RISA-3D board and leave unused bays aside.
3. **Check the spreadsheet.** Read the RISA-3D summary of member forces before you change a section.
4. **Close the loop.** Note which design rows are ready so the next RISA-3D visit does not start by rebuilding the frame.

## First Questions

**Does RISA-3D replace the calculation binder?**  
No. RISA-3D sits beside the drawings and the office sheets you already use.

**Can two engineers share one computer?**  
Yes. Each person keeps a separate RISA-3D profile.

**Will RISA-3D stay workable on an older office laptop?**  
Yes. RISA-3D is meant to stay light during a normal frame review.

**What should a new user try first?**  
One small RISA-3D bay today, then the same design spreadsheet again tomorrow.

## Field Note

RISA-3D is easier to trust when the frame stays smaller than the building it came from. A named session shows which model is active, the pins show which members you will check today, and the closing note tells the next person which load case feeds the design spreadsheet. That record is short on purpose: not a copy of every member, only the path back to the frame that is still open.

The same loop fits a student bay, a client moment frame, or a computer shared by two engineers. Open the last RISA-3D session, confirm one set of member forces, and leave the design spreadsheet easier to read than you found it. Drawings stay where they are. RISA-3D only holds the frame model, the summary, and the handoff.

## One Real Pass

Pick a frame that already has a name: a single bay, a braced frame, or a small roof. Open it in RISA-3D, keep only those members on the board, and read one design row you can point to. A pass is done when that row is tied to a load case and the unused members are no longer in the way. RISA-3D does not need a full rebuild of the building before it is useful.

If the pass feels crowded, the model is too wide. Drop anything that belongs to a different bay and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first member to the last design row, with the summary still matching the member forces on the board.
